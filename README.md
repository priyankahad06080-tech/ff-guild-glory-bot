# 🎮 FF Guild Glory Bot

**Level up your Free Fire guild automatically!**

## ⚡ Super Easy Setup (3 Steps)

### Step 1: Install
```bash
npm install
```

### Step 2: Create `.env` file
Copy this and save as `.env`:
```
GUILD_ID=your_guild_id
PORT=3000
```

### Step 3: Run
```bash
npm start
```

**Done!** Your bot is running on `http://localhost:3000`

---

## 🎯 How to Use

### Check Guild Status
```
http://localhost:3000/guild/status
```

### Level Up Your Guild
```
http://localhost:3000/guild/levelup
```

### See Top Players
```
http://localhost:3000/players
```

---

## 🤖 What It Does

- ✅ Tracks guild experience
- ✅ Levels up automatically
- ✅ Shows player rankings
- ✅ Awards glory points

That's it! Simple & effective! 🚀
